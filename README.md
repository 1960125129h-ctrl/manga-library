# 书库 · 本地漫画书库

把漫画的**下载 → 入库 → 整理 → 阅读**全放在一台机器上的桌面应用（Windows / Electron）。
不依赖任何在线服务，不注册账号，不联网也能看；你的书、进度、标签都只在自己硬盘上。

> 仓库里只有代码。漫画内容、收藏与阅读记录、各站登录凭据都不进版本库（见 `.gitignore`）。

---

## 能做什么

### 书架
- 卡片网格，缩略图自动生成；三种视图密度可调
- **分类 / 标签 / 作者 / 分级 / 平台 / 作品 / 角色**多维度筛选（可叠加拿并集）
- 搜索框直接搜**书名或标签**，`/` 聚焦，右侧 ✕ 一键清空
- 卡片上的 `18+`、`#标签`、作者名都是可点的 chip：点标签或作者 = 按它搜索，不污染筛选状态
- 多选（Ctrl / Shift / Ctrl+A）、右键菜单（分类、标签、封面、重命名、合并、删除）
- 分组（按作者 / 平台 / 作品 / 分级 / 角色）、排序（最近阅读 / 名称 / 收藏优先 / 入库时间）
- 阅读历史、书签、收藏一览

### 阅读器
- 三种模式 × 三种适配（适应宽度 / 适应高度 / 整页），双页跨图、侧栏章节、缩略图
- ← / → 翻页、空格下一页、F 全屏、Esc 退出；记住上次读到哪一页
- 右键图片：加书签、管理图片、查看原图；长图自动拼合与切页校验

### 下载
- **禁漫天堂（18comic）**：填 JM 编号 / 纯数字 / 专辑链接 / 单话链接，走接口直取（不开浏览器、不点免等待、不收 zip）
- **通用站点**：贴目录页链接即可（再漫画、X漫画、Komiic、pixiv、nhentai、E-Hentai、微博、X、抖音 等适配器）
- 下载队列（逐本排队、失败自动重试、关掉应用也留在队列里）、断点续传、下载后自动入库并重建书架
- 动图（mp4）用内置 ffmpeg 转 GIF

### 导入
- `.cbz` / `.zip` 拖进窗口，或直接双击压缩包（已关联），解压成一本并入库
- 手动放文件夹：`<书库根>\漫画\<书名>\第01话\00001.webp`
- 外部目录引用：`外部目录.json` 填已有图包的绝对路径，不复制文件

### 手机上看
- 设置 → 手机端预览：起一个局域网 Web 服务，同一 WiFi 下用手机浏览器打开显示的地址即可（带密码）

## 安装与运行

| 方式 | 文件 | 说明 |
|---|---|---|
| 安装版 | `书库-<版本>-setup.exe` | 走安装向导，建快捷方式、关联 `.cbz`，可在控制面板卸载 |
| 便携版 | `书库-<版本>-portable.exe` | 免安装，双击即用，适合塞 U 盘 |

- **首次启动**会让你选一个**书库根目录**（建议新建空文件夹，例如 `D:\漫画书库`）。界面源码与下载脚本会同步进去。
- 应用自身的配置 / 缓存放在 **`<安装目录>\data`**（安装目录不可写时回落到 `%APPDATA%\shuku-app`）。
- **卸载不会删你的书库目录**；只清程序本体与 `data`。

### 运行要求
- Windows 10 / 11 x64
- 随包自带：`node.exe`（下载与解码用真实 Node 24）、`ffmpeg` / `ffprobe`（动图与转 GIF）、`sharp`（缩略图与取色）
- 可选：Python 3.11 + `pillow opencv-python`（缩略图生成、长图拼合）；不装则自动跳过
- 走代理的站点（pixiv / nhentai / E-Hentai / 抖音 / X）需要本地代理，默认 `127.0.0.1:7890`，可在设置里改成直连

## 仓库结构（开发者）

| 路径 | 说明 |
|---|---|
| `src/` | 渲染层（书架 / 阅读器 / 设置 / 工作台），桌面版与手机端共用 |
| `_app/` | Electron 外壳：窗口、菜单、托盘、IPC、本地 Web 服务、打包配置 |
| `_scripts/` | 下载与整理脚本：`sites/` 站点适配器（含契约校验）、`jm/` 禁漫与通用工具 |
| `icons/` | 应用与 PWA 图标 |
| `docs/` | 下载流程手册、各站取数方案 |

### 开发 / 打包

```powershell
# 开发运行
cd _app; .\node_modules\.bin\electron.cmd .

# 打包（产物在 ..\_dist\）
cd _app; .\node_modules\.bin\electron-builder.cmd --win

# 打包产物验收（33 项：凭据 / 私人数据 / 首启同步 / 升级）
node _scripts\jm\verify-packaged.mjs
```

打包前置物（都在 `.gitignore` 里，换机器要自己补）：`_scripts\tools\ffmpeg`、`_scripts\tools\node\node.exe`、`_app\node_modules`。

## 更新

应用会**自己检查更新**：启动 8 秒后静默查一次 GitHub Releases，有新版本就弹窗（含更新说明），
点「下载并安装」后台下载安装包（任务栏显示进度）→ 拉起安装程序 → 关闭自己。

手动入口有两个：设置面板顶部的「版本 1.0.x · 检查更新」、菜单「帮助 → 检查更新…」。

> 便携版（portable）没法覆盖自己，检测到新版本只会提示并打开发布页，手动换 exe 即可。

弹窗有三个选择：「下载并安装」/「稍后」/「跳过这个版本」。点跳过会记住该版本，之后启动不再打扰；
设置 → 更新 里能看到「已跳过版本 x.y.z」并一键恢复提示；手动点「检查更新」不受跳过影响。

### 发版流程（维护者）

```powershell
# 1) 改版本号（打包和更新检查都以它为准）
#    _app/package.json 的 "version": "1.0.2"

# 2) 打包
cd _app; .\node_modules\.bin\electron-builder.cmd --win

# 3) 发布（Release 的 tag 必须比用户当前版本大）
#    在 GitHub 上 New release -> tag v1.0.2 -> 上传 _dist\书库-1.0.2-setup.exe（可选 portable）
#    资产名建议用 ASCII（如 shuku-1.0.2-setup.exe），中文名在下载/上传环节容易乱码
```

自检命令（发版前跑一次，确认 API 通、能解析出安装包地址）：

```powershell
._app\node_modules\electron\dist\electron.exe _app --update-selftest
# 加 --download 会真下安装包到临时目录（不安装），用来验网速与文件大小校验
```
