# 书库 · 本地漫画书库

把漫画的**下载 → 入库 → 整理 → 阅读**全放在一台机器上的桌面应用（Windows / Electron）。
不依赖任何在线服务，不注册账号，不联网也能看；你的书、进度、标签都只在自己硬盘上。

> 仓库不包含漫画内容、收藏与阅读记录、各站登录凭据；本地 `docs/` 目录由 `.gitignore` 排除，不进入版本库。文档与脚本里的本机路径统一写作占位符。

## 能做什么

### 书架

- 卡片网格，缩略图自动生成；视图密度、卡片宽度、间距、圆角可调
- **分类 / 标签 / 作者 / 分级 / 平台 / 作品 / 角色**多维度筛选（可叠加拿并集）
- 搜索框直接搜**书名或标签**，`/` 聚焦，右侧 ✕ 一键清空
- 卡片上的 `18+`、`#标签`、作者名都是可点的 chip：点标签或作者 = 按它搜索，清空后自动回到刚才那本书的位置
- 多选（Ctrl / Shift / Ctrl+A）、右键菜单（分类、标签、封面、重命名、合并）
- **卡片第一行右端有删除按钮**：平时灰 ✕，悬浮变红；点一下原地变「确认删除」，再点一次即删。不用再翻右键菜单
- 分组（按作者 / 平台 / 作品 / 分级 / 角色）、排序（最近阅读 / 名称 / 收藏优先 / 入库时间）
- 阅读历史、书签、收藏一览
- 收藏、存备注、改简介都不会让页面跳动，滚动位置会被记住

### 阅读器

**四种阅读模式**：

| 模式 | 说明 |
|---|---|
| 单页 | 一屏一页 |
| 双页 | 左右并排，跨页图自动判定 |
| 长条 | 竖向连续滚动，整本宽度可缩放 |
| **横排** | 所有页横向连排，滚轮一路划过去；章节之间插中割条，滚到下一话第 4 页自动转正 |

**横排专有的两个功能**：

- **防剧透**——视口两侧渐变模糊变暗，只看清中间那一页。清晰区会跟随当前页宽度自适应；首页和末页会把贴边那一侧自动关掉，另一侧完整遮住相邻页。分「自动 / 手动」两种模式，左右两侧可各自设为「跟随 / 开 / 关」，切换速度可调（0~400 毫秒）
- **自动翻页**——工具栏点「自动翻页」，按设定间隔往下翻。翻页动作与按方向键完全相同；翻到最后一页自动停止；按键盘、滚轮、点击或触摸都会立即停止

**图片调色**：亮度、对比度、饱和度、色温、色调、锐化、清晰度、降噪、高光、阴影、曲线、褪色、颗粒、杂色共 14 项，另有 5 组一键风格（原图 / 高清 / 柔和 / 浓烈 / 线稿）

**其他**：四种配色（暗黑 / 灰白 / 护眼 / 纸质）、背景图与毛玻璃、预加载页数可配（1~8 页）、← / → 翻页、空格、`F` 全屏、书签、记住阅读位置、长图自动拼合与切页校验

### 下载

- **禁漫天堂（18comic）**：填 JM 编号 / 纯数字 / 专辑链接 / 单话链接，走接口直取（不开浏览器、不点免等待、不收 zip）
- **通用站点**：贴目录页链接即可（再漫画、X漫画、Komiic、pixiv、nhentai、E-Hentai、微博、X、抖音 等适配器）
- 下载队列（逐本排队、失败自动重试、关掉应用也留在队列里）、断点续传、下载后自动入库并重建书架
- 动图（mp4）用内置 ffmpeg 转 GIF

### 导入

- `.cbz` / `.zip` 拖进窗口，或直接双击压缩包（已关联），解压成一本并入库
- 手动放文件夹：`<书库根>\漫画\<书名>\第01话\00001.webp`
- 外部目录引用：`外部目录.json` 填已有图包的绝对路径，不复制文件

### 手机上看

- 设置 → 手机端预览：起一个局域网 Web 服务，同一 WiFi 下用手机浏览器打开显示的地址即可（带密码）

## 安装与运行

| 方式 | 文件 | 说明 |
|---|---|---|
| 安装版 | `shuku-<版本>-setup.exe` | 走安装向导，建快捷方式、关联 `.cbz`，可在控制面板卸载 |
| 便携版 | `shuku-<版本>-portable.exe` | 免安装，双击即用，适合塞 U 盘 |

- **首次启动**会让你选一个**书库根目录**（建议新建空文件夹，例如 `D:\漫画书库`）。界面源码与下载脚本会同步进去。
- 应用自身的配置 / 缓存放在 **`<安装目录>\data`**（安装目录不可写时回落到 `%APPDATA%\shuku-app`）。
- **卸载不会删你的书库目录**；只清程序本体与 `data`。

### 运行要求

- Windows 10 / 11 x64
- 随包自带：`node.exe`、`ffmpeg` / `ffprobe`、`sharp`
- 可选：Python 3.11 + `pillow opencv-python`（缩略图生成、长图拼合）；不装则自动跳过
- 走代理的站点需要本地代理，默认 `127.0.0.1:7890`，可在设置里改成直连

## 更新

应用会**自己检查更新**：启动后静默查一次 GitHub Releases，有新版本就弹窗（含更新说明），
点「下载并安装」后台下载安装包（任务栏显示进度）→ 拉起安装程序 → 关闭自己。

手动入口：设置 → 「更新」页签，或菜单「帮助 → 检查更新…」。

> 便携版没覆盖自己，检测到新版本只会提示并打开发布页，手动换 exe 即可。

弹窗有三个选择：「下载并安装」/「稍后」/「跳过这个版本」。点跳过会记住该版本，之后启动不再打扰；
设置 → 更新 里能看到「已跳过版本 x.y.z」并一键恢复提示。

### 热更新（不用重装应用）

应用会定期从仓库同步**界面代码**和**站点适配器**：

- **站点适配器**：下一次下载自动用新版，连重启都不需要
- **界面代码**：同步后设置面板会出现「界面已更新，点此刷新」，点一下即生效

设置 → 更新 里能看到上次同步时间、本次更新了哪些文件，也可以手动点「立即同步」（默认每 1 小时自动检查一次）。

## 仓库结构（开发者）

| 路径 | 说明 |
|---|---|
| `src/` | 渲染层（书架 / 阅读器 / 设置 / 下载面板），桌面版与手机端共用 |
| `_app/` | Electron 外壳：窗口、菜单、IPC、本地 Web 服务、热更新、打包配置 |
| `_scripts/` | 构建、站点适配器、禁漫下载与各类工具 |
| `icons/` | 应用与 PWA 图标 |
| `AGENTS.md` | **项目规矩与发版流程**（接手或开工前先读） |
| `推送热更新.md` | 热更新操作与问题排查 |
| `docs/` | 本机维护文档；已由 `.gitignore` 排除 |

### 开发 / 打包

```powershell
# 开发运行
cd _app; .\node_modules\.bin\electron.cmd .

# 打包（必须用脚本——里面设了代理和 Electron 镜像，否则下载会超时）
powershell -NoProfile -ExecutionPolicy Bypass -File '_dist\build.ps1'

# 打包产物验收（33 项：凭据 / 私人数据 / 首启同步 / 升级）
node _scripts\jm\verify\verify-packaged.mjs
```

**完整的发版流程（九步，含版本号、日志生成、标签、Release 上传）见 `AGENTS.md` 第三节。**

打包前置物（都在 `.gitignore` 里，换机器要自己补）：`_scripts\tools\ffmpeg`、`_scripts\tools\node\node.exe`、`_app\node_modules`。

## 隐私

- 应用不向任何服务器上传数据；书架、进度、标签全在本地文件里
- 各站登录 cookie 只存在本机，**不进版本库**
- 打包版不含验证码识别组件与测试数据，`library.json` 是空模板
- **文档与脚本已脱敏**：示例里的路径写作 `<书库根>` / `<仓库根>`、用户目录写作 `%USERPROFILE%` / `%LOCALAPPDATA%`，不含真实用户名、私人书架统计与题材标签样例
