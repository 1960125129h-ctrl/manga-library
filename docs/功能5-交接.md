## 1. 用户要的是什么（原话收敛后的需求）

1. **单链接**：解析完**直接铺开整本每一页的缩略图**，**页那一层不挂任何箭头**；用复选框 + 点选 / Ctrl 加减 / Shift 范围选；**默认全不勾**；保留 全选 / 全不选 / 反选；确认后**只下载勾选的页**，没勾的不下。
2. **容器链接**（EH tag 页 / pixiv 作者主页）：
   - 一级 = **作品列表**（封面 + 标题 + 作者/页数；先渲染 60 本，底部「加载更多」，滚动也自动续）；

3. **不要卡片格子**：页那一层**只显示缩略图**，**页码压在缩略图右下角**（勾选框在左上）。
4. 容器这轮**只做 EH tag + pixiv 作者主页**；缩略图要能显示（EH/pixiv 是防盗链图）。

### 2.3 已修的三个真 bug（都在容器链路上，都有实测依据）

1. **EH sprite 地址没下发** → 页面拿到空 thumb，图永远不加载。修：`fetch-book.mjs` 把 `p.thumb` 透传给前端。
2. **`pageUrl` 没传** → 主进程推不出防盗链 Referer（EH 的图床只认同源来源）。修：`pagePreview.pageUrl = 原页面地址`，主进程按它取 origin 当 Referer。
3. **页网格"先建图、后挂进页面"** → 懒加载器把「还没进 DOM 的图」直接丢弃，永远不拉。修：`buildPageGrid` 先把网格挂进 host 再建格子。

### 2.4 另外顺手修掉的（用户明确提过的）

- **已入库的书再下载会退 1 且不下**：页级勾选以前会被「整本已入库直接跳过」那条老分支挡掉。现在页级勾选单独走一条路（只补勾中的页、按 5 位页号命名），三种情形实测退出码都是 0：
  - 已存在的书勾第 3 页 → 真下到 `00003.webp`；
  - 同一页再勾一次 → 跳过已存在，退 0；
  - 整本重下 → 「待下载 0 话(跳过已入库 1)」+ 提示「这本已经完整下过了」，退 0（以前这里退 1）。

## 6. 本会话踩过的坑（下一个人别重踩）

1. **`reader-core.js` 有两份！** build-library 读的是 `_scripts\reader-core.js`（253KB+），**根目录也有一份**同名文件。写错地方会出现「代码改了但书库没变」。改完务必确认 `_scripts\reader-core.js` 的大小/时间戳。
2. **`reader-core.js` 太大，别用 read+edit 链改它**：read 默认只给 2000 行，拿截断的视图去 edit 会把整个文件截断写回（本会话被砍成 57KB 两次）。**改它只用 node 脚本按字符串精确替换**，改完立刻 `node --check` 并核对文件大小。
3. **在 node 脚本里用字符串拼正则必被反斜杠坑**：`'\\s'` 写进文件会变成字面的 `\s`。要生成正则就用 `String.raw`，或者干脆**别用正则**（EH 那段最后改成纯字符串 `indexOf/slice` 才通）。
4. **全局正则对象有状态**：调用过 `str.match(globalRe)` 之后，同一个正则的 `lastIndex` 会被推到末尾，接下来的 `while ((m = re.exec(s)))` 一个都匹配不到（本会话卡了 4 轮就因为这个）。
5. **懒加载的图必须在 DOM 里才不会被丢**：图片元素还没挂进文档时，IntersectionObserver 不生效，队列里会被「不在页面上」清理掉 → 永远不加载。先挂载、再建图。
6. **验收脚本读 UI 状态要留一拍**：点完勾选框立刻读「已选 N」会读到旧值（本会话多次误判成功能坏了）。点 → sleep → 再读。
