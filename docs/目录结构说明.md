## 一、顶层：只留「代码 / 数据 / 启动脚本」

### 目录

| 名称 | 是什么 | 能不能删 |
|---|---|---|
| `src/` | **前端源码**（54 个 ES 模块 + 8 个按域 CSS，入口 `src/index.html`）。改完**不用构建**，重启窗口即生效 | 不能 |
| `_app/` | **Electron 外壳**：`main.js`(2000+ 行) / `preload.js` / `web-server.js` / `ref-colors.js` / `package.json` / `node_modules`(478 MB) | 不能 |
| `_scripts/` | **构建 + 站点适配 + 工具**（见第二节） | 不能 |
| `漫画/` | 真正的漫画目录，一本一个文件夹（**1159 本 / 2335 话 / 120,831 页 / 约 43 GB**；2026-10-22 并入原版 455 本后的数字） | 不能（这是内容） |
| `_cache/` | **【本次新增】** 登录态与临时产物：`chrome-profile/`(约 200 MB，各站登录态)、`home.html` | 可（登录态会丢，要重新登录） |
| `_archive/` | **【本次新增】** 归档：`_css-backup/`、`_预览/`、`jm-caps/`(cap-*.jpg 截图)、`home.html`、`session.jsonl` | 可（都是历史垃圾） |
| `_backup/` | 数据/代码备份：本次 pixiv 改名的 `fix-pixiv-*`、`rename-map.json`、5 个 9 月工作台 zip 快照 | 可（确认不要历史就删） |
| `_thumbs/` | 书架封面缩略图缓存（26.9 MB，会被重建） | 可（重建会重新生成） |
| `_visual-check/` | 界面截图（71 张，38 MB），各类 verify/visual 脚本的默认输出目录 | 可 |
| `docs/` | **【本次新增】** 全部文档（见第三节） | 不能 |
| `icons/` | PWA 图标 | 不能 |
| `.git/` | 版本库 | 不能 |

### 文件

| 名称 | 是什么 |
|---|---|
| `书库.html` | **构建产物**（1.3 MB 单文件），由 `build-library.mjs` 生成。**v0 的 Electron 不读它**（读 `src/index.html`），只有手机/web 那套静态服务还在用它 —— 别手改，会被重建覆盖 |
| `_manifest.json` | **构建产物**（940 KB）：书库内容清单（本/话/页/封面/作者/分级/AI 标记）。前端启动就读它 |
| `library.json` | **你的编辑**：收藏 / 分类 / 标签 / 备注 / 来源 / 封面覆盖（427 KB） |
| `.progress.json` | 阅读进度（按书存话与页） |
| `.workbench.json` | 工作台数据：虚拟图引用 / 参考板 / 收件箱 |
| `reader-prefs.json` | **阅读器全局显示偏好**（模式/适配/方向/侧栏/预览栏/滚轮/配色亮度）。桌面端和手机端共用这一份 |
| `角色作品表.json` | 作品 ↔ 角色词典（含别名） |
| `外部目录.json` | 外部目录挂载配置（当前空） |
| `service-worker.js` / `manifest.webmanifest` | PWA（手机端用）。**改前端后要升 `CACHE_VERSION`**，否则第一刷还是旧文件 |
| `_pkg-boot.log` | 打包版启动日志（tiny，`verify-packaged.mjs` 会读） |
| `.gitignore` | 忽略规则：`漫画/`、`_thumbs/`、`_backup/`、`_archive/`、`_cache/`、数据 json、node_modules |

## 二、`_scripts/`：构建 + 站点适配 + 工具

| 名称 | 是什么 |
|---|---|
| `build-library.mjs` | **构建脚本**：扫 `漫画/` + 识别作者/作品/角色/分级 → 写 `_manifest.json` 与 `书库.html`。支持 `--only "漫画/书名"` 单本增量 |
| `sites/` | 站点适配器：`ehentai` `nhentai` `pixiv` `weibo` `x` `xmanhua` `zaimanhua` `komiic` `douyin` + `fetch-book.mjs`（下载主控）+ `contract.mjs`（返回值契约校验）+ `thumbs.mjs`（缩略图代理）+ `cookies.mjs` |
| `jm/` | 禁漫那套 + 验收/调试工具（63 个 .mjs：`verify-*` 17 个、`check-*` 4 个、`diagnose-*` 3 个、`visual-*` 3 个等） |
| `jm/scenarios/` | verify.mjs 的场景（10 个） |
| `jm/logs/` | 运行日志（下载 / 缓存清理 / F9 性能采样） |
| `lib/` | 公共小库：`downloader.mjs`（图片下载器）、`python.mjs`（Python 解释器探测） |
| `tools/` | ffmpeg（306 MB，抖音动图转 GIF 用） |
| `reader-core.js` | **老单体的源码**（5338 行），只服务 `书库.html` 那套；v0 的 Electron 不用它 |
| `fix-pixiv-names.mjs` | 【本次新增】把历史上 `pixiv <ID>` 名字的书批量改回真标题（带备份与回滚表） |
| `add-comic.mjs` / `merge-book.mjs` / `renumber-chapters.mjs` / `tags.mjs` / `doctor.mjs` / `preset-check.mjs` | 增删改书与自检的小工具 |

## 四、常用命令

~~~powershell
cd 'D:\gong zuo qu\漫画书库重构v0'

# 起界面（改完前端不用构建，重启窗口即生效）
node _scripts\jm\app-start.mjs --restart

# 全量重建书库数据（约 9 秒）
node _scripts\build-library.mjs --lib "D:\gong zuo qu\漫画书库重构v0" --offline

# 只重建一本书（约 2.6 秒）
node _scripts\build-library.mjs --lib "D:\gong zuo qu\漫画书库重构v0" --only "漫画/书名" --offline

# 跑验收场景
node _scripts\jm\verify.mjs boot
node _scripts\jm\verify-all.mjs --fast

# 截个图（默认输出到 _visual-check/）
node _scripts\jm\shot.mjs --html "D:\gong zuo qu\漫画书库重构v0\书库.html" --out "_visual-check\x.png"
~~~
