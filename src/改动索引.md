## 加界面按钮的完整步骤（最常问的）

以"阅读器加一个「自动翻页」按钮"为例：

1. **结构** —— `src/index.html` 里加到 `#bar` 或 `#sidebar`：
   `<button class="b" id="bauto" title="自动翻页">自动</button>`
2. **逻辑** —— 在对应域模块里写函数（阅读器 → `src/reader/nav.js`），并 `export`
3. **接线** —— `src/legacy/core.js` 的接线区加一行：
   `document.getElementById("bauto").onclick = function () { ... };`
   新模块导出的函数还要加进 core.js 顶部的 import
4. **样式**（可选）—— `src/styles/03-reader.css`
5. **重启窗口**：`node _scripts\jm\app-start.mjs --restart` —— **不用构建**

> ⚠️ **漏了第 3 步**：按钮在、点了没反应。而 `verify-injections` **查不出**这个（DOM 接线不是 import）。
> 所以加完按钮**一定要点一下试试**。

## 加一个下载站点

1. `_scripts/sites/xxx.mjs` 写适配器（照 `xmanhua.mjs` 那种最短的抄）
2. `_scripts/sites/index.mjs` 注册
3. **`src/shelf/site-data.js`** 的 `SITES` 加一行（界面上的入口）
4. 返回值会被 `contract.mjs` 校验 —— 字段缺了会**抛错**，不会静默失效
